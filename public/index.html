How to get your Meta credentials (5 min setup):
  1. Ad Account ID — Go to business.facebook.com → Settings → Ad Accounts → copy the number shown. Paste here with act_ prefix → e.g. act_1234567890
  2. Create a Developer App (once) — Go to developers.facebook.com/apps → Create App → choose Business type → name it anything. On the app dashboard → Add Product → Lead Ads Retrieval → Set Up.
  3. Page Access Token — Go to developers.facebook.com/tools/explorer → select your app → click User or Page → Get Page Access Token → select your ViaKashmir Facebook Page → grant: leads_retrieval, pages_manage_metadata, pages_read_engagement → click Generate Access Token.
  4. Extend to 60-day token — Click the blue ⓘ icon next to your token → Open in Access Token Tool → click Extend Access Token → copy and paste below. ⚠ Skip this and it expires in 1 hour!
